# S3 — Simple Storage Service

> **Practical use:** FlowGrid exports uptime reports as CSV to a **private** bucket and gives the
> user a **presigned URL** valid for 10 minutes.
> **Interview use:** "how do you store user files?", "how do you share a private file?", "is S3 a filesystem?"

← [EC2](./ec2.md) · Next: [RDS](./rds.md)

---

## 1. Model

| Concept | Meaning |
|---|---|
| **Bucket** | Top-level container. Name is **globally unique** across all AWS accounts, lives in one region |
| **Object** | Bytes + metadata, up to 5 TB. Identified by **key** |
| **Key** | Full "path" string: `reports/2026/09/inventory-wh-3.csv`. There are **no real folders** — `/` is just a character the console groups by |
| **Prefix** | Leading part of a key; used for listing, permissions, lifecycle rules |
| **Storage class** | Standard, Standard-IA, Glacier tiers… cheaper storage, costlier/slower retrieval |
| **Versioning** | Keep every version of an object; protects against overwrite/delete |
| **Lifecycle rule** | Auto-transition or expire objects by prefix/age |
| **Consistency** | Strong read-after-write for PUT/DELETE (since Dec 2020) |

S3 is **object storage**, not a filesystem: you replace whole objects (no append or in-place edit),
there are no locks, and listing is by prefix. Don't use it as a database.

## 2. Create a private bucket (CLI)

```bash
ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
BUCKET=flowgrid-exports-$ACCOUNT_ID
REGION=eu-west-1

# us-east-1 is special: omit --create-bucket-configuration there
aws s3api create-bucket --bucket "$BUCKET" --region "$REGION" \
  --create-bucket-configuration LocationConstraint="$REGION"

aws s3api put-public-access-block --bucket "$BUCKET" \
  --public-access-block-configuration \
  BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true

aws s3api put-bucket-tagging --bucket "$BUCKET" \
  --tagging 'TagSet=[{Key=project,Value=flowgrid}]'
```

- New buckets already have Block Public Access on, ACLs disabled (Object Ownership = bucket owner
  enforced) and **SSE-S3 encryption by default**. Setting BPA explicitly documents intent.
- Using the account ID in the name avoids collisions and makes the ARN predictable.

Expire old exports automatically (`lifecycle.json`):

```json
{
  "Rules": [
    {
      "ID": "expire-reports-30d",
      "Filter": { "Prefix": "reports/" },
      "Status": "Enabled",
      "Expiration": { "Days": 30 }
    }
  ]
}
```

```bash
aws s3api put-bucket-lifecycle-configuration --bucket "$BUCKET" \
  --lifecycle-configuration file://lifecycle.json
```

Useful everyday commands:

```bash
aws s3 cp ./sample.csv s3://$BUCKET/reports/sample.csv
aws s3 ls s3://$BUCKET/reports/ --recursive --human-readable
aws s3 presign s3://$BUCKET/reports/sample.csv --expires-in 600
aws s3 rm s3://$BUCKET --recursive        # empty before deleting bucket
aws s3api delete-bucket --bucket "$BUCKET"
```

## 3. Permissions: identity policy vs bucket policy

- The **EC2 role** gets `s3:PutObject`/`s3:GetObject` on `arn:aws:s3:::BUCKET/reports/*` via its identity policy ([iam.md](./iam.md#42-permissions-policy--least-privilege-for-the-app)).
- A **bucket policy** is a resource policy on the bucket. Use it for rules that must hold no matter
  who calls — e.g. **deny non-TLS requests**:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "DenyInsecureTransport",
      "Effect": "Deny",
      "Principal": "*",
      "Action": "s3:*",
      "Resource": [
        "arn:aws:s3:::flowgrid-exports-123456789012",
        "arn:aws:s3:::flowgrid-exports-123456789012/*"
      ],
      "Condition": { "Bool": { "aws:SecureTransport": "false" } }
    }
  ]
}
```

```bash
aws s3api put-bucket-policy --bucket "$BUCKET" --policy file://bucket-policy.json
```

**Never** "make the bucket public" to let users download files. That's what presigned URLs are for.
Public buckets are the source of many real-world data leaks.

### 4.2 Configuration beans

```java
@Configuration
public class AwsConfig {

    @Bean
    S3Client s3Client(@Value("${aws.region}") String region) {
        // Credentials come from the default chain → EC2 instance role in prod,
        // ~/.aws profile locally. No keys in code or config.
        return S3Client.builder().region(Region.of(region)).build();
    }

    @Bean(destroyMethod = "close")
    S3Presigner s3Presigner(@Value("${aws.region}") String region) {
        return S3Presigner.builder().region(Region.of(region)).build();
    }
}
```

### 4.3 Upload + presigned download — the two SDK calls you need

These are the isolated SDK calls, not a finished service. In FlowGrid M5 you design the export
feature yourself (which report, who may request it, where the key is stored) and use these inside it.

```java
// Upload: bytes → object. Generate the key yourself; never trust a user-supplied filename.
String key = "reports/inventory/%s.csv".formatted(UUID.randomUUID());
s3.putObject(PutObjectRequest.builder()
                .bucket(bucket).key(key).contentType("text/csv").build(),
        RequestBody.fromBytes(csvBytes));
```

```java
// Presigned GET: a short-lived URL the browser downloads from directly.
GetObjectRequest get = GetObjectRequest.builder()
        .bucket(bucket).key(key)
        .responseContentDisposition("attachment; filename=\"inventory.csv\"")
        .build();
URL url = presigner.presignGetObject(GetObjectPresignRequest.builder()
        .signatureDuration(Duration.ofMinutes(10))
        .getObjectRequest(get)
        .build()).url();
```

Imports: `software.amazon.awssdk.core.sync.RequestBody`, `software.amazon.awssdk.regions.Region`,
`software.amazon.awssdk.services.s3.S3Client`, `…s3.model.PutObjectRequest`, `…s3.model.GetObjectRequest`,
`…s3.presigner.S3Presigner`, `…s3.presigner.model.GetObjectPresignRequest`.

Design questions to answer in your FlowGrid design doc before implementing the export endpoint:

- [ ] Synchronous (build CSV in the request) or asynchronous (return `202` + poll) for large warehouses?
- [ ] Which roles may export (ADMIN, OPS_MANAGER)? Is the export recorded as an audit event?
- [ ] Do you store the key in Postgres so the link can be re-issued later, or is it one-shot?
- [ ] Response shape: `201 {"downloadUrl": "...", "expiresAt": "..."}` — and never log the URL.

### 4.4 Important details

- **Presigned URL lifetime is capped by the signing credentials.** Role credentials are temporary;
  a URL signed by them stops working when that session expires, even if you asked for 7 days. Keep TTLs short (minutes).
- A presigned URL is a **bearer token** — anyone with it can download. Don't log full URLs.
- Large files: use `RequestBody.fromFile(path)` or multipart upload (`S3TransferManager`) rather
  than holding bytes in memory.
- Uploads *from browsers* can use a **presigned PUT** so bytes skip your server.
- Local testing: point the client at **LocalStack** via Testcontainers (`endpointOverride(...)`,
  `forcePathStyle(true)`) — see [`09-testing/testcontainers.md`](../09-testing/testcontainers.md).

## 5. Break → Debug

| Break | Symptom | Cause |
|---|---|---|
| Upload to `reports2/...` | `S3Exception ... Access Denied (403)` | Policy only covers `reports/*` |
| Presigned URL used after 11 min | XML `<Code>AccessDenied</Code> Request has expired` | TTL passed |
| Region mismatch in client | `PermanentRedirect` / `301` | Bucket lives in another region |
| Bucket name reused | `BucketAlreadyExists` | Global namespace |
| Delete non-empty bucket | `BucketNotEmpty` | Empty it first (and all versions if versioned) |

## 6. Interview questions

<details><summary>How would you let a user download a private file?</summary>

Keep the bucket private, authorize the user in my API, then return a presigned GET URL with a short
expiry (e.g. 10 min). The browser fetches directly from S3; my server never streams the bytes.
</details>

<details><summary>How do you store user uploads in a web app?</summary>

Bytes in S3 (keyed by a generated ID, not the user's filename), metadata in Postgres (owner, key,
size, content type, created_at). Authorize via the DB row, serve via presigned URLs. Optionally
upload via presigned PUT, and validate size/type.
</details>

<details><summary>Is S3 a filesystem? What are the consequences?</summary>

No — it's a key→object store. No append, no rename (copy+delete), no partial writes, no locking;
"folders" are just key prefixes. Good for immutable blobs, backups, static assets and exports.
</details>

<details><summary>How do you prevent a bucket from becoming public?</summary>

Block Public Access at bucket and account level, ACLs disabled, least-privilege IAM, deny non-TLS
in the bucket policy, and monitoring (Access Analyzer / Config). Share through presigned URLs or CloudFront.
</details>

<details><summary>What storage class would you use for 1-year-old reports?</summary>

A lifecycle rule transitioning to Standard-IA or a Glacier class (cheaper storage, retrieval fee /
delay), or simply expiring them if nobody needs them — FlowGrid expires exports after 30 days.
</details>
